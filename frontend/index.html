About

Project information

PlagiaScan

An API-based plagiarism checker. Upload a document or paste text and it is scanned against online sources, returning a similarity percentage and the matching content.

How it works

1. Text is extracted from PDF, DOCX or TXT.
2. The text is sent to the scan API.
3. The API returns matching passages, sources and scores.
4. Matches are highlighted and a report is generated.

Features

Text input · File upload · Similarity score · Source matching · Sentence highlighting · Report generation
